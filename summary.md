# Skill Cluster: Summary

A skill cluster is a grouped family of related skills that activate together when a task touches their domain. It is the unit of attention in the Hermes Agent system — lazy loading for expertise, keeping the context window clean and the right procedures present at the right moment. Clusters compound: a single skill is a tool, a cluster is a workshop.

Pete operates the Tower from Hawaii, by phone, through a headless browser peering through a load-bearing reverse proxy on port 1973. The viewer is a bento-tile iframe grid — moveable, resizable tiles, each one a service: command index, audio-stack app, Pete Director, B-Roll. One screen, one gateway, many worlds.

The Tower is half real (folders, ports, HTML, agents, command lists) and half imagined (layers, quarks, pins, garden mazes). Pete owns Vistamations, shares the glory with Madeline and the agents, and never stops building. Madeline skydives in Maui and scuba dives with Cody and Max. Pete rescues kittens, laughs at a dirty-sheet NASA display, hunts a Da Vinci fragment in the Vatican, and cracks the omega code with quarks in a micro Kubernetes cluster.

The skill cluster is the Tower's nervous system. The bento viewer is its eye. Together they let one person run a multi-agent, multi-service system from a beach. That is the spec. That is the glory. All of it, somehow, true.
